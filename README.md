# Hi, I'm Niklas

I build small web apps and tools. What's live at the moment:

- **[imposter-online.com](https://imposter-online.com)** – the party game Imposter, played in the browser
- **[cinenow.app](https://cinenow.app)** – cinema listings near you
- **[checkfirma.de](https://checkfirma.de)** – checks whether a German company name is still available
- **[vokalreim.de](https://vokalreim.de)** – finds vowel rhymes and multi-syllable rhymes for German lyrics, rap and poetry
- **[fahrtrichtung.info](https://fahrtrichtung.info)** – browser extension that shows the direction of travel of ICE trains on bahn.de
